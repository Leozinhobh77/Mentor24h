## 🤖 PARTE 6: COMO FUNCIONA A MÁGICA — 90% SCRIPT + 10% IA

**[JORNALISTA]** Você mencionou 90% script, 10% IA. Explica melhor?

**[ESPECIALISTA]** Quando você digita uma mensagem no WhatsApp, o sistema tenta entender o que você quer. Pode acontecer de 2 formas:

### Cenário 1: Pattern Matching (90% dos casos)

**[ESPECIALISTA]** Você digita: "Preciso tomar remédio gripe todo dia às 14h durante 7 dias".

Sistema detecta: Palavras-chave "remédio", "tomar", horário ("14h"), duração ("7 dias").

Usa regex (padrão de texto) para extrair: Nome = gripe, Horário = 14:00, Duração = 7 dias.

Salva no banco de dados e responde: "Perfeito! Vou avisar todos os dias."

Custo = R$ 0. Porque é tudo script.

**[JORNALISTA]** E a IA?

**[ESPECIALISTA]** A IA entra em 10% dos casos. Quando é ambíguo.

### Cenário 2: IA (10% dos casos)

**[ESPECIALISTA]** Você digita algo confuso: "Aquela coisa que eu te falei ontem".

Sistema tenta pattern matching, não encontra nada específico.

Então envia para Claude (IA da Anthropic) que analisa contexto e entende: Ah, o usuário tá falando de uma meta financeira que mencionou ontem.

IA retorna classificação estruturada e tudo continua.

Custo = R$ 0,001 por mensagem. Bem barato.

**[JORNALISTA]** Então basicamente 90% é automação barata, 10% quando realmente precisa de inteligência?

**[ESPECIALISTA]** Exato. É como você sabe se o sistema é escalável — não depende de IA caríssima. Depende de automação inteligente.

## 🛠️ PARTE 8: A TECNOLOGIA POR TRÁS

**[JORNALISTA]** Como tudo isso funciona tecnicamente?

**[ESPECIALISTA]** O Mentor24h usa uma stack moderna:

**Frontend:** Dashboard web em Next.js/React. Você acessa em mentor24h.com e vê tudo — suas metas, histórico, finanças, tudo visual.

**Mensagens:** Twilio para WhatsApp. Você recebe no app nativo.

**Banco de dados:** Supabase (PostgreSQL). Todos seus dados ficam lá — seguro, criptografado.

**Orquestração:** Make (antes Integromat). É como um maestro que coordena — quando algo acontece (hora de lembrete), Make dispara a ação certa.

**IA:** Claude API (quando necessário). Apenas 10% das mensagens usam IA.

**Agendador:** Cron job no Supabase. Roda 24h/dia, a cada minuto verifica: alguém tem lembrete agora?

**[JORNALISTA]** Então funciona mesmo offline?

**[ESPECIALISTA]** Quase. Você pode usar o dashboard offline (tudo é salvo localmente). Mas lembretes precisam de internet (lógico, vêm do WhatsApp).

## 🚀 PARTE 11: ROTINAS AUTOMÁTICAS (A Inteligência)

**[JORNALISTA]** Você mencionou que sistema oferece insights. Como?

**[ESPECIALISTA]** Através de "Rotinas" — automações que usam IA Claude para ser inteligente.

### Routine 1: Resumo Semanal (Toda Segunda)

**[ESPECIALISTA]** Cada segunda de manhã, Claude analisa sua semana:

Quantas metas você atingiu? Qual foi seu melhor hábito? Qual foi o desafio?

E gera resumo personalizado no tom do seu assistente.

Se você escolheu Sérgio, é contemplativo. Se escolheu Bianca, é animado.

### Routine 2: Detecção de Crise (Contínua)

**[ESPECIALISTA]** Qualquer mensagem que você escreva, sistema analisa em tempo real.

Se detecta ansiedade: "Vejo que você tá ansioso. Respira comigo?"

Se detecta depressão: "Você não está sozinho. Quer conversar?"

Se detecta risco de suicídio: RED ALERT — dispara números de emergência.

### Routine 3: Análise de Padrões (Toda Semana)
