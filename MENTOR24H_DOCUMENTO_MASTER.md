## 🎯 VISÃO GERAL

### O Que é o Mentor24h?

**Mentor24h é o ecossistema definitivo para a vida na palma da mão.**

Não é um aplicativo tradicional. É um sistema completo que funciona via WhatsApp (interface principal) e Dashboard Web (visualização e gestão), oferecendo organização, inspiração, entretenimento e bem-estar — tudo em um só lugar.

### A Proposta de Valor

```
✅ NÃO precisa baixar app
✅ Funciona em qualquer celular (até os mais simples)
✅ Cobra execução (não só organiza)
✅ Personalizado para cada pessoa
✅ Acessível para qualquer idade (8 a 80 anos)
✅ Custo baixo (R$ 9,90 a R$ 99/mês)
```

### Para Quem é o Mentor24h?

- 👨‍💼 Profissionais ocupados que precisam de organização
- 🤱 Mães sobrecarregadas com mil tarefas
- 😰 Pessoas com ansiedade que precisam de estrutura
- 🎓 Estudantes que perdem prazos
- 👴 Idosos que esquecem remédios e compromissos
- 💑 Casais que querem organizar a vida juntos
- 🐶 Donos de pets que precisam lembrar vacinas
- 🚀 Empreendedores que querem produtividade
- **Qualquer pessoa que queira facilitar a vida**

### Diferenciais Competitivos

1. **Tudo no WhatsApp** - Sem necessidade de app
2. **Cobra execução** - Sistema ativo, não passivo
3. **42 categorias** - Cobertura completa da vida
4. **Personalizável** - Cada pessoa monta o seu
5. **Inteligente sem ser caro** - 90% script, 10% IA
6. **Dashboard interativo** - Visão completa e responsiva
7. **Compartilhamento familiar** - Listas e calendários compartilhados

## 🎙️ SISTEMA DE ÁUDIO E PREFERÊNCIAS DE MÍDIA

### Introdução: Por Que Áudio Importa?

Nem toda informação é melhor em texto. Algumas coisas têm **muito mais impacto em áudio**:

- 🧘 **Meditações** (ritmo, respiração, entonação)
- 🙏 **Orações** (voz acolhedora, espiritual)
- 📖 **Histórias** (narrativa imersiva)
- 💪 **Motivação** (voz empolgada impacta mais)
- 🫁 **Técnicas de respiração** (guia passo a passo com ritmo)

**Mas nem sempre a pessoa PODE ouvir:**
- 📵 Sem fone (barulhento, público)
- 🔇 Ambiente de trabalho (precisa ser discreto)
- 📶 Sem dados (precisa economizar)
- ♿ Surdo/deficiente auditivo (precisa de texto)

**Solução: Deixar o usuário ESCOLHER por categoria.**

### Lógica: Sistema Decide Áudio ou Texto

```javascript
async function entregarConteudo(usuarioId, categoria, conteudo) {
  
  // 1. Busca preferência da categoria
  const pref = await db.query(
    `SELECT midia_preferida FROM usuario_preferencias_midia 
     WHERE usuario_id = $1 AND categoria = $2`,
    [usuarioId, categoria]
  );
  
  let midiaPara = pref.midia_preferida; // 'audio', 'texto' ou 'auto'
  
  // 2. Se for AUTO, detecta contexto
  if (midiaPara === 'auto') {
    const usuario = await db.query(
      `SELECT dispositivo, dados_disponiveis, hora_ultima_atividade 
       FROM usuarios WHERE id = $1`,
      [usuarioId]
    );
    
    // Se hora adequada + WiFi: áudio
    if (isWorkingHours() && usuario.dados_disponiveis) {
      midiaPara = 'audio';
    } else {
      midiaPara = 'texto'; // Default: economiza dados
    }
  }
  
  // 3. Entrega no formato correto
  if (midiaPara === 'audio') {
    await enviarAudio(usuarioId, conteudo.audioId);
  } else {
    await enviarTexto(usuarioId, conteudo.texto);
  }
  
  console.log(`✅ Conteúdo entregue em ${midiaPara}`);
}
```

### Como o Sistema Seleciona a Frase

```javascript
// JavaScript/TypeScript que roda no Make ou Backend

function selecionarFrase(assistente, situacao, categoria, variáveis) {
  // 1. Busca frases da situação específica
  const frases = banco_dados.query(`
    SELECT * FROM frases 
    WHERE assistente = $1 
    AND situacao = $2 
    AND ativo = true
    ORDER BY ordem
  `, [assistente, situacao]);
  
  if (frases.length === 0) {
    // Fallback: tenta frase genérica
    return "Olá {{nome}}! Como posso ajudar?"
  }
  
  // 2. Seleciona uma frase aleatória (rotação)
  const frase = frases[Math.floor(Math.random() * frases.length)];
  
  // 3. Substitui variáveis
  let resposta = frase.frase;
  Object.keys(variáveis).forEach(chave => {
    resposta = resposta.replace(`{{${chave}}}`, variáveis[chave]);
  });
  
  // 4. Retorna pronta
  return resposta;
}

// Exemplo de uso:
const resposta = selecionarFrase('lucas', 'sucesso_meta', 'metas', {
  nome: 'Leonardo',
  nome_meta: 'Academia'
});
// Resposta: "Yessss! Demoliu a meta de Academia! Você é top mesmo, Leonardo! 🔥"
```

### Estratégia de Retenção de Mensagens (HOT/WARM/COLD)

Para otimizar custos com armazenamento volumoso, implementamos 3 camadas:

```
HOT (0-30 dias):
├─ Armazenadas com full index
├─ Usadas para IA context
├─ Recuperação: instantânea
├─ Propósito: Conversas ativas
└─ Dados mantidos: 100%

WARM (30-180 dias):
├─ Armazenadas sem index
├─ Apenas logs, sem busca
├─ Recuperação: 1-2 segundos
├─ Propósito: Histórico/compliance
└─ Dados mantidos: 100%

COLD (180+ dias):
├─ Comprimidas (gzip)
├─ Movidas para cheaper storage
├─ Recuperação: sob demanda
├─ Propósito: Backup/LGPD
└─ Dados mantidos: 100% (arquivos)
```

**SQL para implementar arquivamento:**

```sql
-- Mover mensagens antigas para COLD storage
CREATE OR REPLACE FUNCTION arquivar_mensagens_antigas()
RETURNS void AS $$
BEGIN
  -- Move mensagens com mais de 180 dias
  UPDATE mensagens
  SET storage_tier = 'cold'
  WHERE data < NOW() - INTERVAL '180 days';
  
  -- Comprime e move para S3 cheaper
  INSERT INTO mensagens_archive
  SELECT * FROM mensagens
  WHERE storage_tier = 'cold'
  AND data < NOW() - INTERVAL '365 days';
  
  DELETE FROM mensagens
  WHERE storage_tier = 'cold'
  AND data < NOW() - INTERVAL '365 days';
END;
$$ LANGUAGE plpgsql;

-- Agenda para rodar todo dia 1º do mês
SELECT cron.schedule('arquivar-mensagens', '0 0 1 * *', 
  'SELECT arquivar_mensagens_antigas()');
```
